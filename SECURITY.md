# Security Policy

## Supported versions

Only the latest release (Google Play, F-Droid, GitHub Releases) receives security fixes.
Please reproduce against the latest version before reporting.

## Reporting a vulnerability

**Do not open a public issue for security problems.**

Report privately through GitHub:
[Security → Report a vulnerability](https://github.com/Grigoriym/Wallosmobile/security/advisories/new).

Please include:

- the app version and flavor (Google Play or F-Droid), and your Wallos server version,
- a description of the issue and its impact,
- steps to reproduce or a minimal proof of concept.

All communication happens in the GitHub advisory. Reports will be acknowledged on a
best-effort basis; this is a personal project maintained in spare time. There is no bug
bounty.

## Scope

This policy covers the code in this repository. Issues in the Wallos server itself should
be reported to [ellite/Wallos](https://github.com/ellite/Wallos), and issues rooted in a
`grappim-kit` module to [grappim-kit](https://github.com/Grigoriym/grappim-kit/security).
